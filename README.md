# Проект: Система сортировки автомобилей

## Введение

Данный проект реализует консольное приложение для сортировки коллекций объектов типа `Car` (Автомобиль) по различным
критериям. Приложение разработано на языке Java с соблюдением принципов ООП, чистоты кода и конвенций языка.

## Основное задание

Реализовано приложение, позволяющее:

- Выбирать способ заполнения массива автомобилей: вручную, из файла или случайной генерацией.
- Задавать количество элементов.
- Сортировать массив по трём полям: модель, мощность, год выпуска.
- Использовать паттерн "Стратегия" для выбора алгоритма сортировки.
- Применять паттерн "Строитель (Builder)" при создании объектов `Car`.
- Выполнять валидацию всех входных данных (включая данные из файла).
- Работать в цикле до явного выхода пользователя.

## Дополнительные задания

1. Реализована сортировка: чётные значения поля "мощность" — в натуральном порядке, нечётные — на своих местах.
2. Добавлена функция записи отсортированных данных в файл в режиме добавления.
3. Заполнение коллекций осуществляется с использованием Java Stream API.  
   *Кастомная коллекция `CustomCarCollection` реализована на основе массива.*
4. Реализован многопоточный подсчёт вхождений заданного значения мощности.

## Архитектура

- **Паттерны**: Строитель (Builder), Стратегия (Strategy), Валидатор (Chain of Responsibility)
- **Валидация**: отдельные классы-валидаторы для каждого поля
- **Сортировка**: реализована вручную (без `Arrays.sort`), на основе алгоритма быстрой сортировки
- **Тестирование**: ручные тесты в отдельных классах (без использования JUnit)

## Основные классы

- `Car` — сущность автомобиля с полями: модель, мощность, год выпуска
- `Car.Builder` — паттерн Builder с валидацией
- `SortStrategy` — интерфейс стратегии сортировки
- `SortByModel`, `SortByPower`, `SortByYear` — реализации стратегий
- `CustomCarCollection` — кастомная коллекция на основе массива
- `DataGenerator` — генерация данных (ручная, файл, случайная)
- `FileWriterUtil` — запись в файл в режиме добавления
- `SortingApplication` — основной цикл приложения
