Подробное описание

Утилитарный класс для валидации входных данных при создании объекта автомобиля (Car).

Содержит статические методы для проверки корректности значений полей: модели, мощности и года выпуска. Используется при ручном вводе или чтении данных из файла перед созданием экземпляра Car.

◆ isValidModel()

static boolean org.aston.app.util.InputValidator.isValidModel ( String  model)
static

Проверяет, является ли переданная модель допустимой.

Модель считается валидной, если она присутствует в списке разрешённых моделей (указанном в классе DataGenerator) без учёта регистра.

Аргументы
modelстрока с названием модели автомобиля
Возвращает
true, если модель существует в списке допустимых; иначе false

static boolean org.aston.app.util.InputValidator.isValidPower ( int  power)
static

Проверяет, находится ли значение мощности в допустимом диапазоне.

Мощность (в лошадиных силах) должна быть положительной и не превышать разумный технический предел.

Аргументы
powerцелочисленное значение мощности
Возвращает
true, если мощность в диапазоне от 1 до 2000 включительно; иначе false

◆ isValidYear()

static boolean org.aston.app.util.InputValidator.isValidYear ( int  year)
static

Проверяет, находится ли год выпуска в допустимом диапазоне.

Год должен быть не ранее первого выпуска автомобиля (1885) и не позже установленного предельного года (в данном случае — 2025).

Аргументы
yearгод выпуска автомобиля
Возвращает
true, если год находится в диапазоне от 1885 до 2025 включительно; иначе false
