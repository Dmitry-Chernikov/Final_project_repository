static String org.aston.app.random.CarModels.models ( int  number)
static

Возвращает строковое представление модели автомобиля по её индексу.

Индекс используется как позиция элемента в массиве значений перечисления.

Аргументы
numberиндекс модели в списке (0 — AUDI, 1 — TOYOTA и т.д.)
Возвращает
строковое название модели (например, "AUDI")
Исключения
ArrayIndexOutOfBoundsExceptionесли индекс выходит за пределы допустимого диапазона
