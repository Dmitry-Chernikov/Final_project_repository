Подробное описание

Основной класс приложения, реализующий цикл взаимодействия с пользователем.

Предоставляет меню для выбора способа заполнения данных, метода сортировки и дополнительных действий (запись в файл, подсчёт вхождений). Использует паттерн "Стратегия" для реализации различных алгоритмов сортировки.

Основной метод, запускающий цикл приложения.

Отображает меню, обрабатывает выбор пользователя, запускает тесты, генерирует данные, выполняет сортировку, записывает результаты в файл и подсчитывает вхождения заданного значения мощности.
