Подробное описание

Интерфейс CarValidator определяет контракт для валидации объектов класса Car.

Каждый класс, реализующий этот интерфейс, отвечает за проверку одного из полей автомобиля (например, модель, мощность, год выпуска) на соответствие заданным правилам.

Реализации данного интерфейса используются в цепочке валидаторов для комплексной проверки целостности объекта Car перед его использованием.
