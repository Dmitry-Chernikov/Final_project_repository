Подробное описание

Утилитарный класс для генерации и загрузки данных об автомобилях.

Предоставляет методы для создания массива объектов Car тремя способами: случайной генерацией, чтением из файла и ручным вводом через консоль.

◆ fromFiles()

static Car[] org.aston.app.util.DataGenerator.fromFiles ( String  fileName) throws IOException
static

Загружает данные об автомобилях из текстового файла.

Каждая строка файла должна содержать три значения, разделённые запятыми: модель, мощность и год выпуска. Файл читается построчно с использованием Files#lines.

Аргументы
fileNameимя файла, из которого нужно загрузить данные, файл находиться в проекте /src/main/resources/
Возвращает
массив объектов Car, созданных на основе данных из файла
Исключения
IOExceptionесли произошла ошибка при чтении файла
IllegalArgumentExceptionесли строка в файле имеет некорректный формат

Запрашивает у пользователя данные для создания автомобилей через консоль.

Для каждого автомобиля пользователь вводит модель (из списка допустимых), мощность (в л.с.) и год выпуска. Ввод проверяется на корректность с помощью InputValidator.

Аргументы
scannerобъект Scanner для чтения ввода пользователя
countколичество автомобилей, которые необходимо ввести
Возвращает
массив объектов Car, созданных на основе пользовательского ввода
