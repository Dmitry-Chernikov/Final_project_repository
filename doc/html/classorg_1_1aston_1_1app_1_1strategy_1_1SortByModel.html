Подробное описание

Класс SortByModel реализует интерфейс SortStrategy и предназначен для сортировки массива объектов Car по модели в лексикографическом порядке.

Использует алгоритм быстрой сортировки (quicksort) с реализацией метода partition, специфичного для поля model.

◆ partition()

int org.aston.app.strategy.SortByModel.partition ( Car[]  cars,
int  low,
int  high 
)

Выполняет разделение подмассива cars[low..high] на две части относительно опорного элемента.

В качестве опорного выбирается последний элемент подмассива (по индексу high). Все элементы, модель которых меньше или равна опорной (лексикографически), перемещаются в левую часть.

Аргументы
carsмассив объектов Car, подлежащий разделению
lowначальный индекс подмассива
highконечный индекс подмассива
Возвращает
индекс опорного элемента после завершения разделения
