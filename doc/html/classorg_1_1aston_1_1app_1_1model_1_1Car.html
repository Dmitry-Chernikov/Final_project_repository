◆ compareTo()

int org.aston.app.model.Car.compareTo ( Car  other) throws NullPointerException

Сравнивает этот объект Car с другим объектом Car для определения порядка.

Сначала сравнивается модель (лексикографически), затем мощность (по возрастанию), затем год выпуска (по возрастанию).

Аргументы
otherобъект Car, с которым производится сравнение
Возвращает
отрицательное число, если этот объект меньше переданного; положительное число, если этот объект больше переданного; ноль, если объекты равны по всем полям
Исключения
NullPointerExceptionесли переданный объект равен null
