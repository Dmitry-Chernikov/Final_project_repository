\doxysubsection{Подробное описание}
Класс Car\+Power\+Comparator реализует интерфейс Comparator и предназначен для сравнения объектов Car по мощности двигателя в порядке возрастания. 

Используется для сортировки автомобилей по полю power с помощью компаратора.
