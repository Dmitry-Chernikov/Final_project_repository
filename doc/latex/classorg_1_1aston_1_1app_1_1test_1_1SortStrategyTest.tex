\doxysubsection{Подробное описание}
Тестовый класс для проверки реализации стратегий сортировки. 

Содержит методы для тестирования корректности работы алгоритмов сортировки, включая обычную сортировку по мощности и специальную стратегию сортировки чётных значений. Для проверок используется утилита Test\+Utils.
