\doxysubsection{Подробное описание}
Класс Custom\+Test\+Runner предназначен для запуска ручных тестов компонентов приложения. 

Содержит статический метод run(), который последовательно вызывает тесты для различных модулей\+: построения объектов Car, стратегий сортировки и генератора данных. 

Используется вместо сторонних тестовых фреймворков (например, JUnit), в соответствии с требованиями задания — тесты реализованы вручную.
