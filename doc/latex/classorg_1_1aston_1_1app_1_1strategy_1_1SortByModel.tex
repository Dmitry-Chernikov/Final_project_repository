\doxysubsection{Подробное описание}
Класс Sort\+By\+Model реализует интерфейс Sort\+Strategy и предназначен для сортировки массива объектов Car по модели в лексикографическом порядке. 

Использует алгоритм быстрой сортировки (quicksort) с реализацией метода partition, специфичного для поля model.

Выполняет разделение подмассива cars\mbox{[}low..high\mbox{]} на две части относительно опорного элемента. 

В качестве опорного выбирается последний элемент подмассива (по индексу high). Все элементы, модель которых меньше или равна опорной (лексикографически), перемещаются в левую часть.
