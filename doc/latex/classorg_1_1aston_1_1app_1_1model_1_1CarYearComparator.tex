\doxysubsection{Подробное описание}
Класс Car\+Year\+Comparator реализует интерфейс Comparator и предназначен для сравнения объектов Car по году выпуска в порядке возрастания. 

Используется для сортировки автомобилей по полю year с помощью компаратора.
