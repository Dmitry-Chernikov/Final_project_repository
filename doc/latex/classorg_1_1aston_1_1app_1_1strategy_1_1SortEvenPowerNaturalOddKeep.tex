\doxysubsection{Подробное описание}
Дополнительное задание 1\+: сортировка по полю power. 

Четные значения сортируются по возрастанию, нечетные остаются на своих местах. Класс Sort\+Even\+Power\+Natural\+Odd\+Keep реализует интерфейс Sort\+Strategy и предназначен для сортировки массива объектов Car по следующему правилу\+:
\begin{DoxyItemize}
\item Автомобили с чётным значением мощности (power) сортируются по возрастанию.
\item Автомобили с нечётным значением мощности остаются на своих исходных позициях. 
\end{DoxyItemize}

Использует алгоритм быстрой сортировки (quicksort) для сортировки чётных элементов.
