\doxysubsection{Подробное описание}
Утилитарный класс для валидации входных данных при создании объекта автомобиля (Car). 

Содержит статические методы для проверки корректности значений полей\+: модели, мощности и года выпуска. Используется при ручном вводе или чтении данных из файла перед созданием экземпляра Car.
