\doxysubsection{Подробное описание}
Класс Car\+Model\+Comparator реализует интерфейс Comparator и предназначен для сравнения объектов Car по модели в лексикографическом порядке. 

Используется для сортировки автомобилей по полю model с помощью компаратора.
