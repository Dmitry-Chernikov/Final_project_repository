\doxysubsection{Подробное описание}
Утилитарный класс для генерации и загрузки данных об автомобилях. 

Предоставляет методы для создания массива объектов {\ttfamily \doxylink{}{Car}} тремя способами\+: случайной генерацией, чтением из файла и ручным вводом через консоль.
